# Лабораторная работа № 2. Скрытие информации в изображении

Метод Куттера–Джордана–Боссена (КДБ), вариант 8. Буланый С. Е., Хоптий П. В., группа ТКИ-441.

Контейнер — «Фото Телефона» (PNG 1448 × 1086). Сообщение «ТКИ-441 Буланый С.Е.» (256 бит), ключ `TKI-441`.
Метод: амплитудная модуляция синего канала, `B' = clip(round(B + (2M − 1)·V·λ))`, `λ = 0,299R + 0,587G + 0,114B`.

## Состав

| Папка | Что внутри |
|---|---|
| `1_Пустой_контейнер` | Исходные картинки: фото варианта 8, контрольное фото «горы», 5 синтетических (однотонный, градиент, резкие границы, пёстрая текстура, чёрный) |
| `2_Заполненный_контейнер` | Те же картинки после встраивания (КДБ при разных V; stegwm для сравнения) |
| `3_Разница` | Разница заполненного и пустого контейнера: усиленные картинки, маски, список изменённых пикселей |
| `4_Код` | Редактируемый код: `kjb.py` (алгоритм), `app.py` (окно в браузере), эксперименты, `test_kjb.py` (тесты) |
| `5_Схема_алгоритма` | Схема: `algorithm.mmd` (редактируемая, Mermaid), `algorithm.svg`, `algorithm.png` |
| `6_Результаты_анализа` | CSV и JSON с результатами: разные параметры (V, τ, σ, длина сообщения), изменённый и неизменный ЦВЗ, воздействия (шум, JPEG, размытие…), 13 характеристик, stegwm, StegoRevealer |
| `7_Отчёт_и_презентация` | Презентация (шаблон РУТ/МИИТ, оглавление с гиперссылками, источники) |

## Запуск

```
pip install -r 4_Код/requirements.txt
python 4_Код/test_kjb.py          # тесты
```

Окно программы: `4_Код/Открыть программу.cmd` (страница `http://127.0.0.1:8765`).
Скрипты `photo_experiment.py`, `extra_experiments.py`, `external_*.py` дополнительно требуют matplotlib, scikit-image и чужие программы из задания
(код Домашкина и Баурина, stegwm Антропова и Архипова, StegoRevealer) — они сюда не включены.

## Параметры

V (в коде `q`) — сила записи, τ (`n`) — число копий бита, σ (`c`) — радиус «креста» соседей, ключ `key`, длина сообщения `length`.
Контейнер должен храниться без потерь (PNG, BMP, TIFF); после JPEG сообщение не читается.
